# AE Business Dashboards
หน้ารวมแดชบอร์ดผู้บริหารของทุกบริษัทในกลุ่ม All Energy & Utilities · "ตัดสินใจด้วยข้อมูล ก้าวไปอย่างมั่นใจ"

- หน้าเดียว (`index.html`) ไม่มีข้อมูลธุรกิจ — แต่ละแดชบอร์ดมี login Microsoft 365 และเข้ารหัสข้อมูลของตัวเอง
- เพิ่ม/แก้ลิงก์บริษัท: แก้ `GROUPS` ใน `index.html` (url ว่าง = "เร็ว ๆ นี้")
- โลโก้ใน `logos/` · ฟอนต์ Outfit และ IBM Plex Sans Thai (OFL) ใน `fonts/` — ไม่โหลดจากภายนอก
- เผยแพร่: GitHub Pages → Deploy from a branch → `main` / `(root)`
- ออกแบบด้วย Claude Design (13 พ.ย. 2569)
